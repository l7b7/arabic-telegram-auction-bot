# بوت المزادات العربي لتيليجرام

مشروع Python لبوت تيليجرام لإدارة سوق مزادات. هذا الإصدار يحوّل الملف الأصلي `mz.py` إلى مشروع قابل للإعداد والتشغيل عبر Python أو Docker، مع إبقاء قاعدة البيانات خارج صورة Docker.

## المزايا الموجودة في الكود

- نشر المزادات والمزايدة عليها وإشعارات الانتهاء.
- محافظ وأرصدة وتحويلات وأكواد شحن وسحب.
- شحن Telegram Stars وتكامل اختياري مع Binance.
- مسابقات، بطاقات، عجلة حظ، إحالات، قنوات بث واشتراك.
- لوحات إدارة ووكلاء ووسطاء ودعم عربي محلي.
- SQLite ونسخ احتياطي دوري.

## المتطلبات

- Python 3.10 أو أحدث، أو Docker مع Docker Compose.
- بوت تيليجرام أنشأته من `@BotFather`، ومعرّف المستخدم الرقمي للمالك.
- مفاتيح Binance فقط إذا كنت ستفعّل هذا التكامل.

## الإعداد المحلي على Windows

1. نزّل المشروع وافتح PowerShell داخل مجلده.
2. أنشئ بيئة Python وثبّت الحزم:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

3. انسخ `.env.example` إلى `.env`، ثم أدخل `BOT_TOKEN` و`OWNER_ID` على الأقل.
4. شغّل البوت:

   ```powershell
   python bot.py
   ```

على Linux/macOS استخدم `python3 -m venv .venv` ثم `source .venv/bin/activate`.

## التشغيل عبر Docker

انسخ `.env.example` إلى `.env` وأدخل الإعدادات، ثم شغّل:

```sh
docker compose up -d --build
docker compose logs -f
```

يُحفظ ملف SQLite داخل مجلد `data/` على الجهاز المضيف. انسخ هذا المجلد احتياطياً، ولا تحذفه عند تحديث الحاوية. لا تشارك `.env` أو مجلد `data/`.

## الاستضافة المجانية

البوت يستخدم long polling وعمالاً يعملون بالخلفية وقاعدة SQLite محلية. يحتاج عملية تعمل باستمرار وقرصاً دائماً. الخيار الأقرب لهذا التصميم هو VM صغيرة مجانية دائماً، مثل Oracle Cloud Always Free، ثم تشغيل Docker Compose عليها. توفر السعة يعتمد على المنطقة والحساب؛ راجع [حدود Always Free الرسمية](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm).

Render المجاني ليس مناسباً للتشغيل المستمر لهذا الإصدار: خدمة الويب المجانية تتوقف بعد 15 دقيقة بلا زيارات واردة، ونظام الملفات المحلي مؤقت، كما أن عامل الخلفية غير متاح مجاناً. راجع [قيود Render المجانية](https://render.com/docs/free). لتشغيل موثوق 24/7، استخدم استضافة بقرص دائم وعملية مستمرة؛ قد تتطلب خطة مدفوعة.

هذا المشروع ليس موقع ويب. صفحة الويب التي ظهرت سابقاً يُرجّح أنها من رابط `t.me` فتحه تيليجرام أو المتصفح.

## إعدادات البيئة

راجع `.env.example`. لا تضع التوكن أو مفاتيح الدفع أو بيانات التحويل في `bot.py`. إذا سبق نشر أي مفتاح، أبطله وأنشئ بديلاً قبل تشغيل المشروع.

## ملاحظات مهمة قبل تشغيله لمستخدمين حقيقيين

هذا مشروع مزادات يتضمن رصيداً ومدفوعات وتحويلات. النسخة الحالية تحتفظ بأرصدة SQLite كأرقام عشرية، وتستخدم عدة خيوط عمل على اتصال قاعدة بيانات واحد. هذه التفاصيل تحتاج تدقيقاً مالياً وأمنياً واختبار ضغط واستعادة نسخ احتياطية قبل التعامل مع أموال فعلية. ابدأ ببيئة خاصة ومستخدمين تجريبيين، ولا تعتبر إعداد Docker وحده اعتماداً للإنتاج.
